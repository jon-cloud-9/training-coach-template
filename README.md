# Training Coach Template

A Claude Code project that turns Claude into your personal endurance coach. It reads
your real training from intervals.icu (which syncs with Garmin and other watches),
plans each week from an agreed phase template, logs how the week went, and mirrors
the plan to a Notion dashboard.

Start with START-HERE.md.

This is a training aid, not medical advice. If you have pain or an injury, stop and see a professional.
